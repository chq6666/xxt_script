# 学习通课程助手（自动任务点 + DeepSeek 答题）

## 这是什么

学习通的课程任务点经常**挤在同一个页面里**：一个单元下面可能同时挂着「视频 ×2 + 课件 PPT + 章节测验」，而且它们被包在**三层 iframe** 里（页面外壳 → `knowledge/cards` → 各个模块页）。

传统脚本看到页面里有视频就开始播，播完就以为“这页做完了”，直接跳到下一节——结果课件没看、测验没做，任务点全红。

本脚本的做法是：**先解剖页面结构**（识别本页共有几个任务点、每个是什么类型、当前完成到什么状态），再按顺序逐个完成，**只有整页的任务点都完成（或被判定为无需处理）才离开本页**。答题部分接 DeepSeek，支持思考模型。

一句话：**它替你“做任务”，不是替你“点下一页”。**

## 功能特性

| 能力 | 说明 |
| --- | --- |
| 🧭 **页面结构识别** | 自动识别本页任务点：视频 / 音频 / 文档 PPT / 图书阅读 / 章节测验 / 作业 / 考试 / 讨论 / 直播；写在页面里就是哪几个，就做哪几个 |
| ✅ **完成度判定** | 以学习通自己的「任务点已完成」标记为准（`aria-label`、`.ans-job-finished`、接口 `isPassed` 多路回读），视频播完 ≠ 一定完成，会等标记落库 |
| 🎬 **视频自动播放** | 强制 1 倍速（只降不升）、自动静音、后台保活防暂停、断点续播、卡住自动恢复、视频弹窗题自动应对 |
| 📄 **文档 / PPT 自动翻阅** | 自动滚动或点“下一页”，翻到底后调用学习通的完成接口标记任务点，不需要死看到最后一页 |
| 🧠 **DeepSeek 自动答题** | 章节测验 / 作业自动作答并填写；支持单选、多选、判断、填空、简答；答完自动提交并处理确认弹窗 |
| 🧩 **思考模型支持** | 勾选「思考模式」即用 reasoner 类模型：自动剔除 `temperature` 等不支持的参数、自动提高 `max_tokens` 与超时、流式显示“思考中…”，思考过程可在日志里折叠查看 |
| 🚫 **不作答模式** | 一键打开后 **完全不调用 API、不填、不提交**，遇到题目直接判“跳过”继续下一个任务点（默认关闭） |
| 🔓 **题目字体解密** | 部分课程用 `font-cxsecret` 字体把题干/选项存成生僻字（如「媏符媊半媌质媎媍媉媋」）。脚本会**运行时读取页面字体**、按字体内部的字形顺序自动还原成正常汉字；内置清单里没有的新字体版本（含各种子集字体，已实测 48 字 / 137 字 / 161 字三种）会**现场做像素反查**（参考思源黑体/Noto Sans SC 字形，候选池 6763 字）逐字对出来，再交给模型。实在解不出来的字就**按原样保留**（不猜、不跳过），整页题目照样发给模型，日志会说明解出了几个字 |
| 🔁 **跨域模块处理** | 视频/文档/作业常常是跨域 iframe，脚本用子框架代理机制在真正的模块里操作，父页面负责调度 |
| 💾 **进度记忆** | 已完成的单元记在本机，中断后重新打开会接着做；支持“清除本课程进度”重来 |
| 🖥️ **可视化控制台** | 右下角面板：概览 / 任务 / API / 日志 / 设置五个页签，底部「开始刷课 / 暂停 / 跳过当前」，可折叠成一个悬浮小球 |
| 🛡️ **风控保护** | 检测到验证码、人脸识别、滑块等提示立即暂停并提醒，不会硬闯 |
| ⏱️ **拟人节奏** | 任务之间、每题填写之间都有随机延迟，避免操作过快 |

## 三分钟上手

1. **装好篡改猴**（Tampermonkey / 篡改猴），并打开浏览器的「允许用户脚本」开关 —— 见 [安装教程](#安装教程)。
2. **安装脚本**：把 `chaoxing-auto-course.user.js` 拖进浏览器窗口 → 篡改猴弹出安装页 → 点「安装」。
3. **配置 API**：面板 →「API」页签 → 填 DeepSeek 的 Key → 「测试连接」→「保存配置」 —— 见 [配置 DeepSeek API](#配置-deepseek-api)。
4. 打开任意学习通课程页面，右下角出现「学习通课程助手 v1.3.10」，点 **开始刷课**。

> 面板没出现？见 [常见问题](#常见问题) 第一条。

## 安装教程

### 第 1 步：打开「允许用户脚本」

新版 Chrome / Edge 里，篡改猴必须被授权后才能运行用户脚本，否则装好了也不执行。

**Edge**

1. 地址栏输入 `edge://extensions` 回车；
2. 打开左下角（或右上角）的 **「开发人员模式」**；
3. 找到 **「篡改猴」/「Tampermonkey」** → 点 **「详细信息」**；
4. 在详情页里打开 **「允许用户脚本」（Allow User Scripts）** 开关；
5. 确认篡改猴本身是**已启用**状态。

**Chrome**

1. 地址栏输入 `chrome://extensions` 回车；
2. 打开右上角 **「开发者模式」**；
3. 「篡改猴」→「详细信息」→ 打开 **「允许用户脚本」**；
4. 确认扩展已启用。

> 有的版本把这个开关放在扩展详情页的「网站访问权限 / 用户脚本」区域，关键词都是「允许用户脚本 / Allow User Scripts」。找不到时，在扩展页搜索「篡改猴」，进它的「详细信息」页逐项看。

### 第 2 步：安装脚本

**方式 A（推荐）**：把 `chaoxing-auto-course.user.js` 文件直接**拖进浏览器窗口**，篡改猴会弹出安装页，点「安装」。

**方式 B**：右键文件 →「打开方式」→ 浏览器，同样会进入篡改猴安装页。

**方式 C（已有旧版时更新）**：篡改猴面板 →「已安装脚本」→ 点脚本名进入编辑器 → `Ctrl+A` 全选删除 → 粘贴新内容 → `Ctrl+S` 保存。

### 第 3 步：确认装好了

1. 刷新任意学习通课程页；
2. 右下角出现蓝色标题栏 **「学习通课程助手」**，右上角显示 **v1.3.10**；
3. 点开面板能看到「概览 / 任务 / API / 日志 / 设置」五个页签即正常。

## 配置 DeepSeek API

脚本本身不带任何 Key，**必须自己申请一个**（答题功能需要）。不配置也能用：视频、文档、PPT 照常自动完成，只是遇到题目会跳过。

### 申请 Key

1. 打开 **<https://platform.deepseek.com>**，用手机号或邮箱注册并登录；
2. 进入「**充值**」/「账单」，充值少量余额（按题计费，几元钱往往能用很久）；
3. 左侧「**API keys**」→「**创建 API key**」→ 起个名字 → 复制生成的 `sk-...`；
   - **Key 只显示一次**，丢了就删掉重新建；
4. 回到学习通页面，打开脚本面板 →「**API**」页签，按下表填写。

### 填写参数

| 字段 | 填什么 | 说明 |
| --- | --- | --- |
| API 地址 | `https://api.deepseek.com` | 官方地址；用中转/自建服务就填对方地址 |
| 接口路径 | `/chat/completions` | OpenAI 兼容接口的标准路径 |
| 模型名称 | `deepseek-chat` 或 `deepseek-reasoner` | 见下一节；用第三方平台就填平台给的模型名 |
| 思考模式 | 建议在追求正确率时打开 | 打开后脚本会自动用“思考/推理”参数 |
| 流式接收 | 默认开 | 思考时能实时看到“思考中…N 秒”，失败自动回退普通请求 |
| 日志里折叠显示思考过程 | 默认开 | 日志里出现「▸ 思考过程（N 字）」可展开查看 |
| API Key | `sk-...` | 只保存在本机 |
| 温度 | `0.2` | 越低越稳定；思考模型会**自动忽略**该项 |
| 最大 tokens | `4096` | 思考模式会自动抬到 ≥16384 |
| 超时（秒） | `120` | 思考模式会自动抬到 ≥300 |
| 每题间隔（秒） | `2`–`5` | 拟人节奏，防止操作过快 |

填完点 **「测试连接」**：

- 显示「API 连接正常（普通模型）」或「API 连接正常（思考模型，思维链 N 字）」= 成功；
- 显示 401 / 无效 Key = Key 错了；
- 显示「无法连接 API（网络错误）」= 网络/代理问题，见 [常见问题](#常见问题)。

最后点 **「保存配置」**。

### 用第三方中转 / 自建服务

脚本按 **OpenAI 兼容协议**发请求，所以其他平台也可用：

```
API 地址：https://你的中转域名
接口路径：/v1/chat/completions（或平台文档给的路径）
模型名称：平台文档里的模型名（例如 deepseek-v4-pro）
API Key：平台的 Key
```

> ⚠️ 注意：如果学习通页面是 `https://`，而你的接口是 `http://127.0.0.1` 或 `http://局域网IP`，浏览器可能把请求当作**混合内容**拦截，表现就是「网络错误」。本地/自建服务请尽量用 https，或给浏览器放行。

## 模型怎么选（正确率 / 速度 / 费用）

| 方案 | 正确率 | 速度 | 费用 | 适合 |
| --- | --- | --- | --- | --- |
| `deepseek-chat`（不开思考） | 中上 | 快，每题 1–3 秒 | 最低 | 刷课为主、题目简单、想省钱 |
| `deepseek-reasoner` / 任意模型 + **思考模式** | **最高** | 慢，每题 20–120 秒 | 约为普通模型的数倍 | 判断题/多选题多、概念题多、作业要正确率 |
| `deepseek-v4-pro` + 思考（第三方/企业接口常见名） | 视平台，一般不低于官方 | 慢 | 取决于平台单价 | 你已有该平台的 Key/额度 |

**结论**：

- **想最准** → 打开「思考模式」，模型填 `deepseek-reasoner`（官方）或你所用的思考模型名（如 `deepseek-v4-pro`），并把「最大 tokens」调高（≥16384）、超时调大（≥300 秒）。脚本会自动做这些适配。
- **想最便宜** → 关掉思考模式，模型填 `deepseek-chat`。
- 脚本**不校验模型名**：你填什么就发什么。官方 API 的模型名是 `deepseek-chat` / `deepseek-reasoner`；`deepseek-v4-pro` 这类名字通常出现在中转或企业版接口上，以对方文档为准。
- 模型名里含 `reasoner` / `r1` / `thinking` 时，脚本会**自动按思考模型处理**，不必手动勾选。
- 价格以 <https://platform.deepseek.com> 的计价页为准，本文不保证数字时效。

> 小技巧：先用 `deepseek-chat` 刷完视频和文档，遇到重要作业再切到思考模式；或者反过来，期末考试周直接开思考。

## 使用说明

### 面板结构

```
┌─ 学习通课程助手 ─────────── v1.3.10 ─┐
│ 正在播放：3:12 / 18:40    [运行中]   │
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░░  17%          │
│ ┌─概览─┬─任务─┬─API─┬─日志─┬─设置─┐ │
│ │  当前课程 / 章节 / 任务点 / 进度  │ │
│ │  DeepSeek [已配置 deepseek-chat]  │ │
│ └───────────────────────────────────┘ │
│ [开始刷课]  [暂停]  [跳过当前]        │
└──────────────────────────────────────┘
```

- **概览**：当前课程、章节、任务点、进度、API 状态。
- **任务**：章节列表、本章任务点，以及「**本页结构（自动识别）**」——本页有几个任务点、每个是什么、完成到什么状态。
- **API**：模型与 Key 配置、测试连接。
- **日志**：每一步的时间线；答完题会出现「▸ 思考过程（N 字）」可展开。
- **设置**：自动开始、自动打开课程、倍速、自动提交、不作答、答题范围、间隔、清进度等。

### 三个按钮

- **开始刷课**：开始/继续自动执行（若「打开课程页后自动开始」开着，进页面就自动跑）。
- **暂停**：立即停下，可随时继续。
- **跳过当前**：放弃当前任务点，直接下一个（会记为跳过，不会反复重试）。

### 典型流程

1. 打开学习通 → 课程 → 进入某个任务点页面；
2. 面板显示「本页识别到 N 个任务点：视频（待完成）、文档/PPT（待完成）、测验/作业（待完成）」；
3. 脚本按顺序：播视频 → 翻文档/PPT → 答题并提交 → 回读「已完成」标记；
4. 整页都完成（或都跳过）→ 自动点「下一节」，进入下一页继续；
5. 全部做完或遇到验证码时停下并提示。

### 建议先做一次

第一次用建议把「**不作答**」打开，只让脚本刷视频和文档，确认节奏和完成标记都正常；确认没问题再关掉它去答题。

## 常见问题

**Q1：面板没出现 / 装了没反应？**

按顺序排查：① 浏览器扩展页里「允许用户脚本」是否已打开；② 篡改猴与脚本是否都处于「已启用」；③ 脚本是否为最新版（点面板标题栏应显示 v1.3.10）；④ 刷新页面；⑤ 换一个学习通页面（部分页面如考试答题页本来就不注入）。

**Q2：一直是「待机 / 未开始」？**

点 **开始刷课**；或者在「设置」里打开「打开课程页后自动开始」。

**Q3：为什么看到它先播视频，而不是先做题？**

这是设计如此：任务点按页面顺序处理，视频排在前面就先播。你可以在「任务」页签看到本页任务点清单和当前状态。

**Q4：刷完视频直接跳走、题没做？**

v1.3.0 之前会有这个问题（题目在两级 iframe 里，旧逻辑看不到）。请升级到 **v1.3.10**，日志应出现「识别到 N 道题，正在请求 DeepSeek 作答…」。

**Q5：答完题没有自己提交？**

- 检查「设置」里「答完自动提交」是否被关掉（关掉时日志会明确提示“请手动点击提交”）；
- 如果日志出现「有 N 题未能填写，已放弃提交」——模型返回的答案对不上选项，脚本会重问一次，仍失败则为了不提交半对半错的答案而放弃；
- 升级到 v1.3.10：旧版找不到学习通作业页的真正提交按钮（`a.Btn_blue_1[onclick="btnBlueSubmit();"]`），会一直卡在“不提交”。

**Q6：提示「无法连接 API（网络错误）」？**

① 地址和路径是否写错（官方是 `https://api.deepseek.com` + `/chat/completions`）；② Key 是否复制完整（`sk-` 开头）；③ 是否有代理/梯子拦截；④ 用第三方接口时注意 **https 页面不能请求 http 本地地址**（混合内容拦截）。

**Q7：思考模式很慢，是不是卡了？**

不是。思考模型每题要 20–120 秒，面板会显示「思考中…N 秒」，日志有流式进度。嫌慢就关掉思考模式。

**Q8：答案是错的怎么办？**

模型能力决定的：换思考模型、把「温度」调低、把「附加提示词」写成具体课程背景，都能提升；也可以只用它刷视频文档，题目自己做（打开「不作答」）。

**Q9：会不会有风险？**

脚本只是模拟人的点击/播放/填写，带随机延迟与风控暂停，但**任何自动化都有风险**。请遵守你所在学校与课程的规定，自负后果。

**Q10：换电脑 / 重装浏览器后配置还在吗？**

Key 与设置存在浏览器本地（篡改猴存储），换设备需要重新配置；换浏览器同理。

**Q11：需要一直开着页面吗？**

需要，标签页保持打开即可（可以切到后台，脚本会保活视频）。关掉标签页会中断，进度会记录，下次接着做。

## 更新日志

### v1.3.10

- 新增：**遇到不认识的环节直接跳过**。学习通里有些任务点脚本没法自动完成（讨论、直播、论坛、第三方插件等），以前这类页面会一直停在「任务页面加载中…」不动；现在：
  - 讨论 / 直播这类模块，第一轮就判定为“不认识”，直接记账跳过，继续下一个环节；
  - 其它加载不出来的模块，等 4 轮（约 5 秒）没进展就跳过，不会再卡住整门课；
  - 视频 / 音频这类真媒体仍然多等（最多 30 轮），避免网络慢被误判。
- 优化：跳过时日志会写清原因（「跳过「讨论」（页面加载不出可识别内容），继续下一个环节」），概览页也会继续往前走。

### v1.3.9

- 调整：**解不出来的字形不再拦截整页**。以前遇到没收录的字体版本、或抽检没过，会整页跳过不答；现在改成“能解多少解多少”：
  - 内置清单（137/161 字）→ 全量还原；
  - 新字体版本 → 像素反查，**逐字设置信门槛**（相似度 ≥0.86 且明显领先第二名才采用），拿不准的字保持原样；
  - 这些“原样字”连同其余题目一起发给模型，日志提示「解出了 N/M 个字，其余保持原样」，不再丢弃整页。
- 调整：`askQuizBatch` 的 prompt 残留检查从“报错拒发”改成“告警照发”，避免个别字卡住整批题。

### v1.3.8

- 修复：**“模型收到的还是乱码”**——部分课程页面用的是**更小/更新的字体子集**（实测有 48 字、161 字版本，与内置 137 字清单都不同），旧逻辑遇到没收录的版本会把错误字形当正文喂给模型。现在会**现场做像素反查**：把页面字体的字形与思源黑体 / Noto Sans SC 的候选汉字逐字比对（候选池 6763 字），配合「明文按 unicode 递增」的单调约束选最优解。
- 优化：参考字体优先用 `Noto Sans SC` / 思源黑体（学习通字体本身就是思源黑体子集），本机有该字体时逐字准确率可达 100%（实测 48 字子集字体 48/48），日志显示「像素反查/逐字（48 字，平均相似度 0.97）」。
- 优化：内置 137 / 161 字清单仍走“按字形顺序秒解”的快路径（日志「内置字形清单」），只有清单对不上时才启动像素反查（约 2–3 秒，仅首题一次）。

### v1.3.5

- 改进：**题目字体解密改成“运行时自适应”**——不再只靠内置 137 字对照表，而是从页面的 `@font-face` 里取出字体文件，解析 cmap 与字形顺序，自动把加密生僻字映射回正常汉字。网站以后换字体版本（只重排码位）也能自动解开；解析后还会用 canvas 做字形抽检，抽检不过就回退内置表。
- 修复：**离开本节时不点确认框**——学习通在本节还有未完成任务点时会弹「当前章节还有任务点未完成，是否去完成？」，脚本以前点完“下一节”就干等，永远等不到跳转。现在会自动识别这个弹框并点里面的「下一节」继续。
- 现在面板日志会显示「题目字体映射：运行时字形反查（137 字，抽检 9/9 通过）」或“改用内置对照表”，方便判断当前用的是哪种方式。
